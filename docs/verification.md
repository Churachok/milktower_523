## Ограничения текущей проверки

Docker daemon не запущен, `/var/run/docker.sock` отсутствует; `sudo -n` требует пароль. Поэтому фактические Docker-сборка, `nginx -t`, smoke через контейнерный Nginx и runtime-лимиты не проверены. Полноценный backend отсутствует, а GPU-конфигурация остаётся будущим расширением. CI расширен тестами Python и smoke скоринга через Nginx; локальная успешная проверка не означает успешного запуска CI на GitHub.

После обновления структуры визуально просмотрены главная, личный кабинет и очередь сотрудника; сохранены локальные скриншоты (исключены из Git). Проверены выход, публичный расчёт 1,7 млн ₽ / 18 мес. → вход с перезагрузкой → один новый черновик `PT-2026-0051`, вход по прямой ссылке на него и смена роли через профиль с сохранением `PT-2026-0049`. Подробности структуры — [interface.md](interface.md). Демо запущено только на localhost. Хостовый Node.js 26.10.0; контейнер/CI используют ветку 22, сборка в контейнере не подтверждена.

## Что ещё не проверено

Docker daemon недоступен: `/var/run/docker.sock` отсутствует, системная и пользовательская службы Docker неактивны. Поэтому сборка контейнеров, `nginx -t`, HTTP smoke через Nginx и реальные runtime-лимиты **локально не проверены**. Существующий Docker context только `default`; альтернативного работающего daemon не обнаружено.

Backend и ML ещё не содержат кода и Dockerfiles. CPU/GPU Compose для них — подготовленный контракт интеграции. Реальные серверные сессии, база, файлы, ML-инференс и расход ресурсов модели не проверялись. Метрики модели и результат интеграционного сценария добавляют владельцы сервисов после реализации.

В [CI](../.github/workflows/ci.yml) настроены аудит репозитория, frontend-тесты и сборка, проверка трёх Compose-конфигураций и запуск Docker-демо с HTTP smoke. Полная интеграция требует сервисов коллег. Результат CI будет доступен после отправки соответствующего коммита на GitHub. Команды — в [docker.md](docker.md), порядок сдачи — в [submission.md](submission.md).
