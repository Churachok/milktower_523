# Синтетические документы для проверки

Эти два PDF нужны для ручного прохождения новой заявки. Их можно выбрать прямо из клонированного репозитория; генератор или дополнительные зависимости для запуска приложения не нужны.

| Файл | Тип в форме | Содержание |
|---|---|---|
| [statement.pdf](statement.pdf) | Выписка | Синтетические поступления и списания за 12 месяцев |
| [financial-report.pdf](financial-report.pdf) | Финансовая отчётность | Сводные показатели того же вымышленного бизнеса |

Для соответствующей заявки использовать: выручка **12 000 000 ₽**, расходы **7 000 000 ₽**, обязательства **0 ₽**, возраст бизнеса **3 года**; цель — «Закупка сырья». Компания и контакт уже предзаполнены демонстрационными значениями.

Оба файла явно помечены как синтетические и не являются банковскими документами. Mock проверяет тип, расширение и размер файла, сохраняет только метаданные. Содержимое PDF не распознаётся и не участвует в скоринге.
