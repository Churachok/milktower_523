# E2E Проверочные сценарии (Скоринг и ML)

Эти сценарии проверяют `calculate_score` и `build_result_payload` на признаках из `ml/fixtures/mock-companies.json`, без backend. Автотест: `PYTHONPATH=ml python3 -m unittest discover -s ml/tests -v`. Для UI-сценариев см. [test-scenarios.md](test-scenarios.md).

Исправлены fixtures B/C/D: раньше фактические баллы были 1150/500/1350 и не соответствовали заявленным исходам. Пороги сохранены. Текущие ожидаемые значения: **A=1000, B=500, C=250 (350 после документа), D=650, E=0**. `Decision` в этих сценариях означает рекомендацию, а не автоматически присвоенный статус UI.

HTTP `/score` отдельно рассчитывает финансовые признаки из годовой анкеты и не копирует финансовые значения fixtures. Для повторения доменных баллов через UI нужно перенести соответствующие годовые доходы/расходы и остаток долга с учётом формулы нагрузки; одного совпадения ИНН недостаточно.

### Сценарий A — Идеальный клиент → Одобрено
* **Компания:** ООО «Ромашка» (ИНН 7701234567)
* **Продукт:** `working`, 1 500 000 ₽, 12 мес.
* **Ожидание:** score = 1000, рекомендация `APPROVED`.

### Сценарий B — Нестабильные финансы → Ручное рассмотрение
* **Компания:** ИП Петров (ИНН 7702345678)
* **Продукт:** `working`, 1 000 000 ₽, 12 мес.
* **Ожидание:** score = 500, рекомендация `MANUAL_REVIEW`.

### Сценарий C — Проблемный клиент → Дозапрос
* **Компания:** ООО «СтройМастер» (ИНН 7703456789)
* **Продукт:** `equipment`, 5 000 000 ₽, 36 мес.
* **Ожидание:** score = 250, рекомендация `NEED_MORE_INFO`.
* **Действие:** после загрузки документов (`documents_provided=true`) скоринг пересчитывается → `MANUAL_REVIEW`.

### Сценарий D — Молодая компания → Одобрено с условиями
* **Компания:** ООО «НовТех» (ИНН 7704567890)
* **Продукт:** `working`, 800 000 ₽, 6 мес.
* **Ожидание:** score = 650, рекомендация `APPROVED_WITH_CONDITIONS`, `approved_amount` = 560 000 ₽.

### Сценарий E — Отказ
* **Компания:** ООО «Закат» (ИНН 7705678901)
* **Продукт:** `working`, 2 000 000 ₽, 12 мес.
* **Ожидание:** score = 0, рекомендация `REJECTED`, `approved_amount` = null.
