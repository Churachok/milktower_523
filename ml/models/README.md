# Модель и артефакты

Модель пока не выбрана. [manifest.example.json](manifest.example.json) — шаблон для ML-разработчика; пустые поля не означают наличие обученной модели.

После выбора модели добавить `manifest.json` с идентификатором и версией, типом подхода, лицензией, происхождением данных, признаками, метриками и ограничениями. Для каждого необходимого артефакта указать точный URL/версию и SHA-256. Если используется набор правил, описать его версию и тесты без вымышленных весов или метрик.

Крупные веса и обучающие выгрузки исключены из Git. Metadata `.md` и `.json` в этом каталоге разрешены. Скрипт получения модели и её интеграция в `ml/Dockerfile` должны воспроизводимо собирать CPU-образ из исходников без закрытых аккаунтов и платных ресурсов. Артефакт скачивается и проверяется при сборке, затем входит в образ; для обычного запуска inference внешний интернет не нужен. Лицензии добавляются в THIRD_PARTY_NOTICES.

Для новой версии модели следует обновить манифест и образ, измерить ресурсы на ПК с 4 CPU / 8 ГБ и повторить общий сценарий. Исключение весов из Git не заменяет их доступность для жюри.
