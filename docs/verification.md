## Исправлено при интеграции

- Обычный Compose теперь поднимает полный стек; прежний mock вынесен в `compose.demo.yaml`.
- Вход создаёт серверную cookie-сессию, перезагрузка восстанавливает роль, выход отзывает сессию.
- Backend вызывает правила Михаила по HTTP; собственный расходящийся скоринг заменён транспортным адаптером.
- Результат ML сохраняется отдельно от решения сотрудника. Дозапрос сбрасывает старую оценку; сбой ML не меняет статус/историю.
- Исправлено удаление документов в форме при HTTP 204 backend.
- Устранён обязательный ключ Groq при старте нового ML API. AI включается отдельно, основной продукт работает автономно.
- Добавлены lock-файл optional ML, миграция сохранённого результата, сквозной smoke и проверки backend/AI в CI; документация обновлена.
