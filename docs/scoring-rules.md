# Финансовые признаки и правила скоринга

## 1. Используемые признаки
| Признак | Источник | Смысл |
|---|---|---|
| `monthly_revenue_avg` | Анкета / ФНС | Средняя выручка в месяц, ₽ |
| `revenue_trend_6m` | Анкета / ФНС | Динамика выручки за 6 мес. (доля) |
| `net_profit_avg` | Анкета | Средняя чистая прибыль, ₽ |
| `debt_burden_ratio` | Анкета + БКИ | Долговая нагрузка (платежи / доход) |
| `bki_has_delays` | Мок БКИ | Флаг наличия просрочек |
| `bki_max_delay_days` | Мок БКИ | Максимальная просрочка, дней |
| `bki_credit_history_months` | Мок БКИ | Глубина кредитной истории, мес. |
| `egrul_status` | Мок ЕГРЮЛ | Статус компании (ACTIVE / LIQUIDATED) |
| `tax_arrears` | Мок ФНС | Наличие налоговой задолженности |
| `requested_amount` | Заявка | Запрошенная сумма, ₽ |
| `amount_to_revenue_ratio` | Расчёт | `requested_amount / (monthly_revenue_avg * 6)` |

## 2. Матрица рекомендаций
| Балл (0-1000) | Рекомендация кредитной логики | Действие сотрудника |
|---|---|---|
| ≥ 750 | `APPROVED` | Рассмотреть предложение исходной суммы |
| 550–749 | `APPROVED_WITH_CONDITIONS` | Рассмотреть уменьшение суммы на 30% |
| 350–549 | `MANUAL_REVIEW` | Провести ручной анализ |
| 200–349 | `NEED_MORE_INFO` | Определить и запросить дополнительные сведения |
| < 200 | `REJECTED` | Рассмотреть отказ и объяснить причину |

Рекомендации не меняют статус автоматически. Статусы UI: `submitted`, `manual_review`, `needs_info`, `approved`, `rejected`, `issued`; переход выбирает соответствующая роль.

## 3. Шкала и преобразование анкеты

Старт — 100 баллов, затем применяются правила из `ml/domain/scoring.py`. Итог ограничивается 0–100 и умножается на 10; `delta` факторов остаётся в исходной шкале 0–100. Неактивная компания получает 0 независимо от бонусов. Верхний предел исправлен: ранее благополучные fixtures давали 1350 при контракте 0–1000.

`ml/demo.py` преобразует годовую выручку и расходы в месячные, рассчитывает прибыль и нагрузку `(debt / 12 + loan_payment) / (revenue / 12)`. Погашение существующего остатка долга за 12 месяцев — явное синтетическое допущение. `documents_provided` даёт +10 только за `kind=additional`, не за первоначальный пакет. Для внешних признаков используется тестовый профиль ИНН; финансовые данные анкеты имеют приоритет. Полный ответ содержит эти допущения для просмотра сотрудником.

**Ограничения:** это детерминированные демонстрационные правила, а не обученная или валидированная кредитная модель. Начальная оценка насыщается на 1000 для благополучных компаний; бонус за документ не доказывает снижение реального риска. Кейс допускает такой подход, но качество на реальных заёмщиках не подтверждено.
