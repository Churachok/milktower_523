## Docker и версия сдачи

Локальный Docker daemon недоступен: `/var/run/docker.sock` отсутствует, запуск через sudo требует пароль. Предыдущий интегрированный main `a72c735` уже прошёл реальную сборку и Nginx/E2E в [CI](https://github.com/Churachok/milktower_523/actions/runs/40272280759). Изменённые Docker-образы, сверка build commit и перезапуск контейнера проверяются повторно в CI для нового commit перед тегом сдачи.

Workflow `Submission package` запускается по тегу `submission-*`, повторяет CI, экспортирует только зафиксированные исходники и проверяет manifest распакованного архива. Точный hash находится в SUBMISSION.json; результаты упаковки и checksum проверяются после коммита. Успех старого CI не считается подтверждением новой версии.

## Практические ограничения

Фактическая внешняя HTTPS-публикация не выполнялась: подготовлены конфигурация, секреты через env и инструкция; не предоставлены сервер и домен. Живые запросы Groq не выполнялись и не требуются основной версии. GPU runtime отсутствует и не проверялся. Содержимое документов не хранится. Кредитная точность синтетических правил, промышленная авторизация, HA и нагрузочная устойчивость не заявляются.
